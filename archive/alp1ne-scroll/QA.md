## 首次打开与加载遮罩

- 使用独立本地服务器将 `portfolio.json` 人为延迟 30 秒；延迟期间 `site-ready=false`、`aria-busy=true`，仅显示不透明的品牌启动层。
- 慢加载状态下 DOM 不再包含 `IMAGE IN THE MAKING`，截图未出现旧素材占位页。
- 正常加载完成后 `site-ready=true`，启动层从 DOM 移除；首屏海报和视频就绪类均存在。
- 精确阻断 `portfolio.json` 时，启动层保留并显示“作品资料加载失败”和“重新加载”按钮；恢复网络后点击按钮可正常进入页面。
- iPhone 14 模拟视口为 390×844，无横向溢出；开启减少动态效果后进度条动画为 `none`，正常加载后启动层同样移除。

## 手机与减少动态效果

- 独立测试页面固定为 390×844 CSS 视口，菜单按钮可见。
- 菜单打开后 aria-expanded=true，Shift+Tab 从关闭按钮返回菜单末尾链接。
- 点击菜单项后关闭菜单，恢复 main 的交互能力并进入作品索引。
- 手机详情宽 362px、左右各 14px；页面无横向溢出。
- 模拟 prefers-reduced-motion 后：视频停在 0 秒且 paused=true；长展映占位高 0；展映为 relative/grid，clip-path 为 none，四个季节全部可访问。
- 清除了模拟媒体和设备设置，关闭了临时测试页。
- 浏览器手机模拟截图存在缩放比例异常，因此手机端采用交互和实际 DOM 布局尺寸进行核验；桌面有正常截图证据。
- 没有在真实 iOS Safari 或屏幕阅读器上进行完整测试。iOS 媒体解锁流程已实现，不等同于真实设备兼容性认证。
