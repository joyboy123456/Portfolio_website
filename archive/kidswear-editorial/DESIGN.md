# 童装作品集 · 视觉方向

## 目标

为 AI 童装电商视觉设计师制作求职作品集。先完成画廊框架，再填充自行重做的案例。主要访客是招聘方，希望快速了解搭配判断、AI 模特生成、服装还原和最终交付质量。

## 参考锁定

**主参考：用户提供的童装商品搜索截图。** 已保存在 `references/kidswear-style-reference.png`，仅用于设计判断，不作为作品发布。画面中的主要作品为女童服装主图，具有浅灰底、清爽低饱和配色、同款多搭配、模特姿态和商品文字排版等特点，主体商品图多为方形。

用户明确选择：白底黑字的时装画册感，突出搭配和成图。

**辅助参考：**

- [COS Spring Summer 2025](https://www.cos.com/en-us/campaign/spring-summer-2025-womenswear)：查看页面内容及实际浏览器画面，借鉴简洁导航、独立季节主题、大画幅作品和少量配文。
- [TOTEME Collections](https://toteme.com/en-ap/collections)：查看系列与服装品类的组织方式，借鉴分类维度和筛选重置，不照搬商业购物功能。
- ARKET 页面在获取时显示维护，未作为实现依据。
- Refero 本地 typography、anti-ai-slop、craft-details 和 motion 参考：可读字号、固定画幅、清晰焦点、减少动态效果和真实的空图状态。当前没有可用的实时 Refero MCP 工具。

## 设计决定

| 决定 | 来源 | 用途 |
| --- | --- | --- |
| 白底、近黑字、直角大画幅 | 用户风格选择 + COS | 支撑招聘方快速浏览作品 |
| 浅粉灰、浅绿灰、暖灰、蓝灰 | 用户截图的童装配色 | 仅用于图片尚未填充时的留白画框，实际作品拥有主要色彩 |
| 中文宋体标题 + 简洁正文 | 用户童装内容 + Refero 字体指南 | 保留画册感，通过中文标题准确定位服务 |
| 方形封面，支持 3:4 / 4:5 | 用户截图 | 优先适配电商主图，也容纳独立模特图 |
| 季节和服装品类是独立标签 | 用户分类要求 + TOTEME 分类参考 | 同一作品可跨季节，不需要重复存储 |
| 原始单品 / 搭配过程 / 最终成图 | 用户业务描述 | 展示搭配判断与执行，而非只有最终图片 |
| 12 组筹备案例，图片字段为空 | 用户明确要求 | 先完成框架，后续集中填充 |
| 不展示未经核实的销量与履历 | 现有材料范围 | 不把网站结构误写成已完成的业绩 |

## 视觉约束

画布 #fcfcfa，文字 #22221f，辅助文字 #73736d，细线 #deded8。重点来自作品和排版，不使用大面积装饰渐变、圆角卡片阴影或童趣贴纸。季节色只出现在留白框中。页面不生成或展示替代作品照片。

临时名称为“衣着之间”；姓名、职位和联系信息通过 portfolio.json 维护。选图之后仍以作品配色和服装内容为主，不根据站点色调改变作品颜色。

## 实现

沿用 React + TypeScript + Vite。Tailwind 用于响应式布局；主要组件样式使用 CSSProperties。图片路径、分类及文案独立放在 public/portfolio.json 中，便于后续填充。原版梦幻页面备份到 archive/reverie。
